# Achadinhos

Site público oficial do projeto **Achadinhos**.

## Páginas

- Página inicial: `index.html`
- Termos de Serviço: `termos-de-servico.html`
- Política de Privacidade: `politica-de-privacidade.html`

Este repositório foi preparado para publicação pelo GitHub Pages a partir da branch `main`, pasta `/root`.

## Crescimento orgânico — versão em desenvolvimento

A branch `feat/crescimento-organico-facebook-v1` adiciona:

- `grupos.html` — página pública para localizar grupos por nicho.
- `grupos.js` — configuração de convites (vazia por padrão; preencher links reais).
- `extensao-facebook/` — assistente Manifest V3 para montar textos e registrar **publicações manuais**.
- `docs/PLANO-ORGANICO-30-DIAS.md` — plano de distribuição orgânica e metas experimentais.

Leia `extensao-facebook/README.md` e execute `extensao-facebook/TESTES.md` antes de publicar/instalar.
